# 🧩 Algo Puzzle Board

An interactive **Data Structures & Algorithms visualization platform** designed to make learning DSA intuitive, visual, and engaging. This project focuses on helping students and developers *see algorithms in action* rather than just reading theory.

🔗 **Live Demo:** https://algo-puzzle-board-production-d547.up.railway.app/

---

## 🚀 Features

- 🎯 Interactive visualization of **20+ algorithms**
- 🧠 Covers core **DSA & problem-solving concepts**
- ⚡ Real-time animations for better understanding
- 🖱️ User-friendly, click-based interactions
- 🌐 Deployed and accessible online

---

## 📚 Algorithms & Concepts Included

### 🔢 Sorting Algorithms
- Bubble Sort  
- Selection Sort  
- Insertion Sort  
- Merge Sort  
- Quick Sort  

### 🌲 Data Structures
- Arrays  
- Stacks  
- Queues  
- Linked Lists  
- Trees  

### 🌐 Graph Algorithms
- BFS (Breadth First Search)  
- DFS (Depth First Search)  
- Dijkstra’s Shortest Path  

### ♟️ Puzzle & Backtracking Problems
- N-Queens Problem  
- Knight’s Tour
